# 程序执行的基本过程

一个程序执行的时候，CPU 会根据程序计数器里的内存地址，从内存里面把需要执行的指令读取到指令寄存器里面执行，然后根据指令长度自增，开始顺序读取下一条指令。

**理解一个a=1+2的计算过程**
**指令**，不同的CPU有不同的指令集，对应着不同的汇编语言和不同的机器码。
例如MIPS指令集，指令是一个32位数，高6位代表操作码，代表不同指令，剩下的26位不同指令类型所表示内容不同。
指令的执行通常包含四个阶段，Fetch取得指令、Decode指令译码、Execution执行指令、Store数据回写。其中不同的阶段通常是不同组件完成的。（也有说**取指、译码、执行、访存、写回**）
**指令类型**：通常分为5类，数据传输、运算、跳转、信号、闲置

# 存储器相关

## 存储器的层次结构
寄存器、各级缓存cache、内存、硬盘。
寄存器，数量通常在几十到几百个之间；
Cache，采用SRAM静态随机存储器的芯片，访问快，存储数据量少；
内存，采用DRAM动态随机存储器；
SSD/HDD，固态硬盘/机械硬盘。

每个存储器只和相邻的一层存储器设备打交道，并且存储设备为了追求更快的速度，所需的材料成本必然也是更高，也正因为成本太高，所以 CPU 内部的寄存器、L1\L2\L3 Cache 只好用较小的容量，相反内存、硬盘则可用更大的容量，这就我们今天所说的存储器层次结构。

## Cache
L1Cache通常分为数据缓存和指令缓存两个部分，L1和L2缓存是单个核心独占的，L3是多个核心共享的。
Cache分为多个Cache Line。**直接映射、全相连、组相连等策略。**

想要代码更快，就提高缓存命中概率，数据缓存和指令缓存的命中率！

### 缓存一致性
缓存机制都相似的面临一致性问题，当我Cache中的数据在指令执行过程中被修改后，怎么在多级存储中进行同步？

**写直达**：把数据同时写入内存和Cache中。写入数据前，查看数据是否已经在Cache中，在则先写入Cache，紧接着写入内存。
**写回**：发生写操作时，新的数据仅仅被写入Cache Block中，只有被修改过的Block被从Cache中替换掉时才写回到内存中。被修改的Block会被打上tag，标志需要写回。

*L1、L2缓存是每个cpu独有的，假设现在同一个block，多个核心都要访问并修改这个块，那怎么在不同核心的缓存中进行一致性保持？*
**写传播**：某个CPU核心的Cache数据更新是，必须要传播到其他核心的Cache。总线嗅探，写之后向总线广播时间。
**事务的串行化**：所有核心看到的数据操作顺序必须一致。MESI协议
