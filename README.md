# WorkSkills

个人工作技能知识库，主要用于沉淀后端开发、AI 基础设施、AI Agent、计算机基础与面试相关笔记。

## 内容结构

```text
.
├── AI-Agent/              # AI Agent 与大模型基础
│   └── I-LLM-Basic/
├── AI-Infra/              # AI 基础设施相关八股与实践整理
├── CS-Interview-Notes/    # 计算机基础与面试知识点
│   └── Redis/             # Redis 专题笔记
└── InterviewRecord/       # 笔试、面试记录与图片材料
```

## 主要主题

- **AI Agent**：大模型基础、Transformer 等学习笔记
- **AI Infra**：AI 基础设施相关知识整理
- **CS Interview Notes**：计算机基础、后端八股与 Redis 专题
- **Interview Record**：笔试面试记录、复盘材料与图片附件

## 使用说明

本仓库可作为 Obsidian Vault 使用，建议通过 [Obsidian](https://obsidian.md/) 打开以获得更好的双链和本地笔记体验。

本地配置目录已通过 `.gitignore` 忽略，包括 `.claude/`、`.obsidian/` 和 `.claudian/`。
